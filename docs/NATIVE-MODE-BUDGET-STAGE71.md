Stage71 adds a conservative memory-budget-aware EDID mode selector. The old advisory largest-resolution selector remains unchanged; the new API filters modes exceeding 16384×16384 or a caller's 2–4 framebuffer copies, using checked arithmetic. This prevents a future GPU backend from choosing an unallocatable mode. Tests cover 1080p versus higher resolutions, invalid buffer counts and overflow. No DRM modeset or native login.
