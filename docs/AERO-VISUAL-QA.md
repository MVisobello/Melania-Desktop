# Melania Aero Visual QA

Aggiunto `tools/aero-ux-lab`: prototipo grafico Tk/X11 autonomo con icone del tema Aero Classic FINAL, menu Start a due colonne, Files, taskbar e pannelli Aero.

È stato realmente eseguito su Xvfb e acquisito uno screenshot.

**Non** rappresenta una build verificata Rust/Wayland. Si tratta di un banco di prova visivo e interattivo, da usare per trasferire stile e comportamento a GTK4/Smithay.

Esecuzione: `python3 tools/aero-ux-lab/melania_aero_live.py`. Test: `python3 tools/aero-ux-lab/test_aero_live.py`.
